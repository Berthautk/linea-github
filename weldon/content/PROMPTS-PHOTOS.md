# Photos des concours : prompts pour générateur d'images IA

Une photo par **thème** suffit : chaque concours de Weldon est rattaché à un thème (champ `theme` de `concours.json`).

## Comment faire

1. Ouvrez un générateur d'images gratuit : ChatGPT, Gemini, Microsoft Copilot (Designer) ou Meta AI.
2. Collez le prompt du thème **tel quel** (en anglais : les générateurs le comprennent mieux).
3. Choisissez **le format paysage (16:9)** si l'outil le propose.
4. Téléchargez l'image et envoyez-la en indiquant le **nom de fichier** (ex. `police.jpg`).

Chaque prompt se termine par la même consigne de style, pour que toutes les photos aillent ensemble.

**Style commun (déjà inclus dans chaque prompt)** : *photorealistic, natural daylight, shallow depth of field, warm and respectful, Cameroon, no text, no logos, no flags, wide 16:9 landscape.*

## Intégration (pour le développeur)

1. Copier l'image dans `web/img/themes/<fichier>` (largeur 1600 px, JPEG qualité 80, environ 150 Ko).
2. Ajouter dans `content/photos.json` : `"police": { "fichier": "police.jpg", "credit": "Image générée par IA" }`.

La photo apparaît alors en bannière sur la fiche de tous les concours du thème, et sur leurs cartes.
